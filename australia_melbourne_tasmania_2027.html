Melbourne + Tasmania

两个人一起出发，Tasmania 改为全程自驾。住进海边与山间民宿，沿 Great Eastern Drive 慢慢停靠，也给自己做饭留出舒服的晚上。

优先锁 Plan B，再订一台车走完整个 Tasmania。

两人可以轮换驾驶，推荐 Hobart 机场取车、Launceston 机场还车；多出的一天留给 Freycinet 或 Cradle Mountain 看天气调整。

Tasmania 连续自驾路线

Hobart 机场取车、Launceston 机场还车，车辆贯穿整个塔州段。每天尽量控制在 1-3 小时驾驶，景点日不赶夜路。

Hobart Port Arthur Coles Bay St Helens Cradle Mountain Launceston

取还车与驾驶节奏

HBA 落地直接取小型自动挡，LST 起飞前还车；两位驾驶人都加入租车合同。

每天出发前确定主驾与替补，约 90 分钟交换一次。尽量 17:30 前抵达住宿，黄昏后减少驾驶。

仍需注意

Cradle Mountain 开车到 Visitor Centre 后换官方 shuttle，运营时段内不能自驾进入 Dove Lake Road。

山路与海岸公路不追赶导航时间；下载离线地图，油量低于半箱就在大镇补给。

住宿区域速查

两个人更适合选择带厨房、洗衣机和停车位的整套民宿。海岸与山区优先提前采购，晚上回住处自己做饭。

Melbourne

优先 CBD / Southbank，方便 SkyBus、tram、NGV、Yarra River 和一日团集合。

关键词: Melbourne CBD / Southbank

Hobart

住 CBD / Salamanca 方便步行；有车后也可住 Sandy Bay 的整套公寓，停车和采购更轻松。

采购: Woolworths / Coles · 找带停车位和厨房

Freycinet

住 Coles Bay 两晚，优先整套 cabin / cottage。晚餐选择有限，抵达前在 Swansea 采购两晚食材。

采购: Swansea · 找 full kitchen / BBQ

Bay of Fires

想看海住 Binalong Bay，重视超市与加油住 St Helens。只住一晚时，St Helens 执行更稳定。

采购: St Helens · 当晚适合海鲜简餐

Cradle Mountain

住 Cradle Valley 两晚，减少 Launceston 当日往返。优先 cabin，准备早餐、徒步午餐和一顿热晚饭。

采购: Sheffield / Deloraine · 山区选择少

Launceston

住 CBD / Cataract Gorge 周边，选择带停车位的公寓；最后一晚可清空冰箱并整理行李。

关键词: Launceston CBD / West Launceston

每日节奏

Plan B｜16 天双人自驾推荐版Melbourne 4 天 + Tasmania 连续自驾 11 晚 + 返程
Melbourne 城市与近郊 · D1-D4
D1住 Melbourne CBD / Southbank。交通: SIN → MEL，抵达后用 SkyBus / taxi / rideshare 进城，不取车。安排: 只做入住、超市补给、Yarra River 轻松散步，倒时差。
D2住 Melbourne CBD / Southbank。交通: 全程 tram / 步行。安排: Flinders Street、Federation Square、Yarra River、NGV、Southbank。两个人可以安排一顿正式晚餐。
D3住 Melbourne CBD / Southbank。交通: tram 到 Fitzroy / Collingwood，区域内步行。安排: 咖啡馆、设计店、小店、Brunswick Street / Smith Street。今天保持城市慢节奏。
D4住 Melbourne CBD / Southbank。交通: Great Ocean Road 可继续报小团；若两人都习惯左侧驾驶，可租车日游并轮换驾驶。安排: 12 Apostles、Loch Ard Gorge；自驾版最多选 3-4 个主停靠点，日落前返程。双人轮换避免夜路
Hobart 与 Tasman Peninsula · D5-D8
D5住 Hobart CBD / Sandy Bay 民宿。交通: MEL → HBA，机场取自动挡后进城，约 20 分钟级别。安排: 入住、超市采购、waterfront 轻松散步。今天只熟悉车辆与停车。首次采购可自炊
D6住 Hobart CBD / Sandy Bay 民宿。交通: 市区步行；kunanyi 视天气短途自驾，或把车留在住处。安排: Salamanca Market（周六）、Battery Point、waterfront；天气通透再上 kunanyi。
D7住 Hobart CBD / Sandy Bay 民宿。交通: 自驾 Richmond 往返，单程约 30 分钟；MONA 可改搭 ferry。安排: Richmond Bridge、老镇与咖啡馆，作为左侧驾驶适应日。下午回 Hobart 选 MONA 或休息。
D8住 Port Arthur / Eaglehawk Neck cottage。交通: Hobart → Sorell → Tasman Peninsula，纯驾驶约 1.5 小时，沿途分段停靠。安排: Tessellated Pavement、Tasman Arch、Devils Kitchen，下午 Port Arthur Historic Site。住半岛避免当天往返。乡间民宿提前买晚餐
Great Eastern Drive · D9-D11
D9住 Coles Bay / Freycinet cottage。交通: Port Arthur → Sorell → Orford → Swansea → Coles Bay，纯驾驶约 4 小时。安排: Orford 海边短走、Swansea 午餐与采购、Spiky Bridge；这天只走顺路小镇，不额外绕行。Swansea 采购准备两晚食材
D10住 Coles Bay / Freycinet cottage。交通: 仅住宿与国家公园停车点之间短途移动。安排: Wineglass Bay Lookout 轻松版，或 Wineglass Bay Beach 完整版；下午 Honeymoon Bay / Cape Tourville。
D11住 St Helens / Binalong Bay 民宿。交通: Coles Bay → Bicheno → Scamander → St Helens，纯驾驶约 2.5 小时。安排: Bicheno Blowhole、海岸步道与午餐；傍晚到 Binalong Bay 看橙色岩岸。晚餐在 St Helens 采购或外食海鲜。Bicheno 停留Bay of Fires
Cradle Mountain 与北部 · D12-D16
D12住 Cradle Valley cabin。交通: St Helens → Derby → Scottsdale → Launceston 外围 → Sheffield → Cradle Valley，纯驾驶约 4.5 小时。安排: Derby 咖啡、Sheffield 壁画镇并完成山区采购；16:30 前抵达，不在黄昏赶山路。加满油山区采购
D13住 Cradle Valley cabin。交通: 开车到 Visitor Centre，白天换官方 shuttle 前往 Dove Lake / Ronny Creek。安排: 好天气走 Dove Lake Circuit；风雨较大改 Enchanted Walk、Pencil Pine Falls。晚上回 cabin 做热饭。园区 shuttle天气弹性
D14住 Launceston CBD / West Launceston 公寓。交通: Cradle Valley → Sheffield → Deloraine → Launceston，纯驾驶约 2.5 小时。安排: Sheffield 与 Deloraine 二选一慢停，下午 Cataract Gorge。车继续保留，方便住宿与机场。
D15住 Launceston CBD / West Launceston 公寓。交通: 自驾 Tamar Valley / Evandale 半日，或把整天留在 Launceston。安排: 作为全程缓冲：天气好去 Tamar Valley，疲劳就逛 City Park、Design Tasmania 并整理行李。
D16返程或 Melbourne 机场附近过夜。交通: LST → MEL → SIN。若衔接不顺，D16 只飞 MEL，住机场附近，D17 回 SIN。安排: 不排景点，专心转机和返程。

Melbourne + Hobart · D1-D6
D1-D4住 Melbourne CBD / Southbank。交通: 城市段 tram / 步行；Great Ocean Road 可选团或双人轮换自驾。安排: CBD、NGV、Yarra River、Fitzroy / Collingwood 和 Great Ocean Road。
D5-D6住 Hobart CBD / Sandy Bay 民宿。交通: MEL → HBA，机场取车；市区步行与短途自驾结合。安排: Salamanca、Battery Point、waterfront，Richmond / MONA 二选一。D6 完成东海岸食材采购。
Tasman Peninsula + East Coast · D7-D10
D7住 Port Arthur / Eaglehawk Neck cottage。交通: Hobart → Tasman Peninsula，约 1.5 小时。安排: 自然海岸地貌 + Port Arthur，半岛住一晚。
D8住 Coles Bay / Freycinet cottage。交通: Port Arthur → Orford → Swansea → Coles Bay，约 4 小时。安排: Orford 短停、Swansea 午餐采购，傍晚到 Coles Bay。
D9住 Coles Bay / Freycinet cottage。交通: 国家公园内短途驾驶。安排: Wineglass Bay 徒步 + Cape Tourville / Honeymoon Bay。
D10住 St Helens / Binalong Bay 民宿。交通: Freycinet → Bicheno → St Helens。安排: Bicheno 海岸、Bay of Fires 日落；St Helens 补油和采购。
Cradle Mountain + Launceston · D11-D15
D11住 Cradle Valley cabin。交通: St Helens → Derby → Sheffield → Cradle Valley，约 4.5 小时。安排: 沿途小镇分段停靠，天黑前抵达山区。
D12住 Cradle Valley cabin。交通: Visitor Centre 停车后换官方 shuttle。安排: Dove Lake / Ronny Creek 徒步，天气差则走低海拔短线。
D13住 Launceston 公寓。交通: Cradle Valley → Sheffield / Deloraine → Launceston。安排: 小镇慢停，下午 Cataract Gorge。
D14住 Launceston 公寓。交通: 自驾 Evandale / Tamar Valley 半日。安排: 北部缓冲、采购伴手礼、整理行李。
D15返程或 Melbourne 机场附近过夜。交通: LST 机场还车 → MEL → SIN；若衔接不顺，拆出 D16。安排: 不排景点，留足还车与转机时间。

下一步查票与预订

先锁机票与异地还车，再按路线订可取消民宿。Coles Bay、Cradle Valley 和 Tasman Peninsula 的厨房型住宿最值得先订。

国际段

SIN → MEL / MEL → SIN，分别拉 Plan A 和 Plan B 的具体日期。

澳洲国内段

MEL → HBA、LST → MEL。确认衔接时间，不为省一晚酒店硬接早晚航班。

厨房型民宿

优先锁 Port Arthur、Coles Bay、Cradle Valley；筛选 entire place、kitchen、washer、free parking。

租车

Hobart 机场取、Launceston 机场还，小型自动挡；登记两位驾驶人并确认异地还车费、零赔付额选项。
