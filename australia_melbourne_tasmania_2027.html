2027/02-03 Melbourne + Tasmania Two-person Road Trip

Melbourne + Tasmania

两个人一起出发，Tasmania 改为全程自驾。住进海边与山间民宿，沿 Great Eastern Drive 慢慢停靠，也给自己做饭留出舒服的晚上。

优先锁 Plan B，再订一台车走完整个 Tasmania。

两人可以轮换驾驶，推荐 Hobart 机场取车、Launceston 机场还车；多出的一天留给 Freycinet 或 Cradle Mountain 看天气调整。

Tasmania 连续自驾路线

Hobart 机场取车、Launceston 机场还车，车辆贯穿整个塔州段。每天尽量控制在 1-3 小时驾驶，景点日不赶夜路。

Hobart Port Arthur Maria Island Coles Bay St Helens Cradle Mountain Stanley Launceston

取还车与驾驶节奏

HBA 落地直接取小型自动挡，LST 起飞前还车；两位驾驶人都加入租车合同。

每天出发前确定主驾与替补，约 90 分钟交换一次。尽量 17:30 前抵达住宿，黄昏后减少驾驶。

仍需注意

Cradle Mountain 开车到 Visitor Centre 后换官方 shuttle，运营时段内不能自驾进入 Dove Lake Road。

山路与海岸公路不追赶导航时间；下载离线地图，油量低于半箱就在大镇补给。

新增景点与取舍

固定 16 天时，三项新增体验全部保留；用 Great Ocean Road 的一天换取 Tasmania 更完整的东南与西北路线。

优先保留

Tasman Island Cruise：与 Port Arthur 同日，10:00–13:00 出海，下午参观 Historic Site。

Maria Island：住 Triabunna / Orford，预留完整一天搭船登岛。

Stanley：住两晚，完整体验 The Nut、老镇、Highfield 与海岸。

降级或移除

移除：Great Ocean Road 一日游，为 Tasmania 多留一天。

备选：Richmond、MONA、kunanyi、Tamar Valley，按天气与体力临场加入。

不建议删：Freycinet、Bay of Fires、Cradle Mountain。

Melbourne 城市适应 · D1-D3
D1住 Melbourne CBD / Southbank。交通: SIN → MEL，抵达后用 SkyBus / taxi / rideshare 进城，不取车。安排: 只做入住、超市补给、Yarra River 轻松散步，倒时差。
D2住 Melbourne CBD / Southbank。交通: 全程 tram / 步行。安排: Flinders Street、Federation Square、Yarra River、NGV、Southbank。两个人可以安排一顿正式晚餐。
D3住 Hobart CBD / Sandy Bay 民宿。交通: 上午 Fitzroy / Collingwood，傍晚 MEL → HBA；机场取车后进城。安排: Great Ocean Road 本版移除。抵达 Hobart 后只入住、采购和熟悉车辆。
Hobart、Tasman Peninsula 与 Maria Island · D4-D7
D4住 Hobart CBD / Sandy Bay 民宿。交通: 市区步行，天气好再短途自驾 kunanyi。安排: Salamanca、Battery Point、waterfront；Richmond / MONA 只作为天气差时替补。
D5住 Port Arthur / Eaglehawk Neck cottage。交通: 07:15 左右从 Hobart 出发，09:15 前抵达 Tasman Island Cruises Booking Centre。安排: 10:00–13:00 Tasman Island Cruise，午餐后用约 3 小时参观 Port Arthur Historic Site。必订巡游保暖防水
D6住 Triabunna / Orford cottage。交通: Port Arthur → Sorell → Orford / Triabunna，约 2–2.5 小时，沿途停 Tessellated Pavement、Tasman Arch。安排: 恢复与转场日；抵达后确认次日 ferry、采购午餐和饮水。
D7住 Triabunna / Orford cottage。交通: 车停 Triabunna，搭约 45 分钟 ferry 前往 Maria Island；岛上只能步行或骑行。安排: Darlington、Fossil Cliffs / Painted Cliffs 二选一；岛上没有商店和咖啡馆，食物与饮水全部自带。ferry 必订自带补给
Freycinet 与 East Coast · D8-D10
D8住 Coles Bay / Freycinet cottage。交通: Triabunna → Swansea → Coles Bay，约 2 小时。安排: Swansea 午餐与采购、Spiky Bridge；下午 Cape Tourville 或 Honeymoon Bay。
D9住 Coles Bay / Freycinet cottage。交通: 住宿与国家公园停车点之间短途移动。安排: Wineglass Bay Lookout 轻松版，或 Wineglass Bay Beach 完整版。
D10住 St Helens / Binalong Bay 民宿。交通: Coles Bay → Bicheno → Scamander → St Helens。安排: Bicheno Blowhole 与海岸午餐，傍晚 Bay of Fires；在 St Helens 加满油并采购山区食材。
Cradle Mountain、Stanley 与返程 · D11-D16
D11住 Cradle Valley cabin。交通: St Helens → Derby → Scottsdale → Sheffield → Cradle Valley，约 320–340 km。安排: 全程最长驾驶日，Derby 咖啡、Sheffield 采购，16:30 前抵达。
D12住 Cradle Valley cabin。交通: 开车到 Visitor Centre，白天换官方 shuttle。安排: 好天气走 Dove Lake Circuit；风雨则走 Enchanted Walk / Pencil Pine Falls。
D13住 Stanley cottage。交通: Cradle Valley → Sheffield / Devonport → Burnie → Stanley，约 200–220 km。安排: 分段停 Sheffield 或 Burnie，下午抵达 Stanley 看 The Nut 与海边日落。
D14住 Stanley cottage。交通: 当地短途驾驶。安排: The Nut summit walk / chairlift、Highfield Historic Site、Stanley Heritage Walk；傍晚去 Godfreys Beach 看企鹅。
D15住 Launceston CBD / West Launceston 公寓。交通: Stanley → Burnie → Devonport → Launceston，约 225 km。安排: 早出发，下午 Cataract Gorge；Tamar Valley 与 Evandale 本版不再单独安排。
D16返程或 Melbourne 机场附近过夜。交通: LST → MEL → SIN。若衔接不顺，D16 只飞 MEL，住机场附近，D17 回 SIN。安排: 不排景点，专心转机和返程。

下一步查票与预订

先锁机票与异地还车，再按路线订可取消民宿。Cradle Valley、Stanley、Port Arthur 和 Triabunna / Orford 最值得先订。

国际段

SIN → MEL / MEL → SIN，分别拉 Plan A 和 Plan B 的具体日期。

澳洲国内段

MEL → HBA、LST → MEL。确认衔接时间，不为省一晚酒店硬接早晚航班。

厨房型民宿
